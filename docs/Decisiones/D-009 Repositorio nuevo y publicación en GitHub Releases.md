# D-009 · Repositorio nuevo y publicación en GitHub Releases

## Contexto
El proyecto 3D empieza de cero y necesita su repositorio público y un sitio donde publicar el ejecutable para los amigos.

## Decisión
- Repositorio nuevo y público `CabadaAndres11/thalandor-online-3d`; el del prototipo 2D (`thalandor-online`) se queda como está.
- Las primeras versiones se publican en **GitHub Releases** (`.zip` con el ejecutable). itch.io se añade más adelante.

## Por qué
No rompe los enlaces ni el GitHub Pages del prototipo. GitHub Releases no requiere preparar nada (sesión ya iniciada) y basta para probar con 2 o 3 amigos.

## Alternativas consideradas
- Renombrar el repositorio del prototipo y reutilizar `thalandor-online`.
- itch.io desde el principio (cuenta, página y `butler`).
